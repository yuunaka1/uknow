# yuKnow

yuKnowは、ユーザー自身の学習データをクライアント側で管理し、AIを活用する語学学習アプリケーションです。サブスクリプションやサーバーは不要で、Gemini APIキーのみで動作します。

---

## 搭載機能

### ☕ AI英会話 (フリートーク)
Gemini Multimodal Live APIを利用したリアルタイムの対話練習機能です。
- **レベル設定**: CEFRレベル（A1〜C2）を指定し、AIの語彙や話す速度を調整できます。
- **フィードバック**: 会話終了後に「良かった点」「改善すべき表現」「自然な言い換え」をまとめたレポートを生成します。

### 📸 写真描写
TOEICのスピーキングテスト形式を想定した写真描写トレーニングです。
- **画像生成**: AIが自動的に画像を生成し、様々なシチュエーションで練習できます。
- **評価機能**: 発話音声と画像情報を解析し、フィードバックを提供します。
- **実践形式**: 45秒の準備時間と45秒の解答時間で練習を行うことができます。

### 🎤 田中渓メソッド
特定のトピックに関するスピーチ構成案の作成から、模擬インタビューまでをサポートする機能です。
- **構成・原稿の作成**: 日本語のメモから、論理的な構成と英語の原稿を作成します。
- **模擬面接**: 作成した原稿をもとに、AIとの対話シミュレーションを行います。

### 🧠 フラッシュカード
Google Docsに作成したノートから単語帳を自動生成する機能です。
- **反復学習**: 忘却曲線に基づくアルゴリズムでクイズを出題します。
- **データ同期**: Google Docsを更新することで、単語帳の内容が同期されます。

### 🎧 シャドーイング
語学学習用のメディアプレイヤー機能です。
- **発音診断**: ユーザーの録音とお手本音声を比較し、スコア化と改善点の提示を行います。
- **再生機能**: A-Bリピート、再生速度の変更、自動録音に対応しています。

### 💬 レッスン音声評価
英会話レッスンの録音データなどを解析し、学習レポートを作成する機能です。
- **振り返り支援**: 録音された音声を基に、改善可能なフレーズや表現のアドバイスを提示します。

### ⚡ 独り言スピーチ
日本語の課題文を即座に英語で発話する瞬間英作文トレーニングです。
- **音声対応**: AIが音声で課題を提示し、ユーザーの回答を添削します。

### 🔊 発音矯正
ユーザーの発話をAIが聞き取り、リアルタイムで発音の修正点を提示する機能です。

## プライバシーと費用
- **クライアントサイド処理**: サーバーを介さず、ユーザーのブラウザから直接Google（Gemini / Google Docs）のAPIと通信します。
- **費用**: ソフトウェアの利用自体は無料です。Gemini APIの利用状況に応じて、Google側の規定による料金が発生する場合があります。

---

## 使い方

1. **APIキーの取得**: Google AI StudioからGemini API Keyを取得します。
2. **アクセス**: アプリケーションのURLにアクセスします。
3. **設定**: 「設定」タブでAPIキーを入力し、AIの音声モデルなどを選択して利用を開始します。
